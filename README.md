# forensic-tools

This is a repository to share some useful tools.

### templates

Directory with templates of reports, Information Security Policies, playbooks, runbooks...

### ERUNT

ERUNT is a useful tool to extract registry keys while the system is still on.

### fsum

fsum.exe is a useful tool to generate a list of file hashes.
Download fsum_v2.52.zip file in this repository only if the official website https://www.slavasoft.com/fsum/ is unavailable.

### linux_collector

linux_collector.sh is a script for extracting volatile data on Linux systems. 

### onion_analyzer

onion_analyzer.py is a script that collect onion links in a website and open each one in a TOR browser tab.
You neede to cofigure the TOR path on the system. The script collects the TOR path in the environment variable called TOR_BROWSER_PATH. If the local variable is not set, the script prompts the user for the path at runtime.

### windows_collector

windows_collector.bat is a script for extracting volatile data on Windows systems.
