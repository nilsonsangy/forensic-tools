# Information Security Policy (ISP)

This directory contains templates and examples for creating an **Information Security Policy (ISP)** document. An ISP is a critical document that outlines the rules, guidelines, and best practices for protecting an organization's information assets.

## Structure

- **`pt-br/`**: Contains the Information Security Policy template in Portuguese.
- **`eng/`**: Contains the Information Security Policy template translated into English.

## About the Policy

The provided templates are designed to help organizations create a standardized and comprehensive Information Security Policy. These templates include:
- A glossary of terms.
- Guidelines for data protection.
- Security measures and best practices.

Feel free to use and adapt these templates to meet your organization's specific needs.
